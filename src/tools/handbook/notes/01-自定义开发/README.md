## 关键入口

- 测试表单设计：`http://<内网地址>/web/#/custom/form-definition/design`
- 测试表单发布：`http://<内网地址>/web/#/custom/form-definition/publish`
- API Host：`http://<内网地址>/apis/`
- Token：`Bearer <你的Token>`

> 提示：内网地址，需在内网或 VPN 下访问。浏览器自动化与数据库直连方法见 [[04-环境接入与排障/环境与排查方法]]。
