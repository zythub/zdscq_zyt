### ⚠️ 最重要的一条

**大屏上"特种作业人员 XX 人"这类统计数字，要去「施工人员台账」改，不是「特种作业人员台账」。**

原因：统计接口 `ryzzfltjsl` 读的是 `tud_dfdcsgrytz.gwgzlb`（人员工作类别）字段，
这个字段**全库只有施工人员台账这一张表有**。改特种作业人员台账只会影响"人员资质列表"，改不了统计数字。

### 看到"没数据"先查这 3 件事

1. **前端有没有传 `sys_org_number`**（项目号，当前是 `DW001`）——不传查不到任何数据
2. **对应表里到底有没有数据**（见第 3 节的排查 SQL）
3. **这个模块是不是根本还没有维护页面**（见第 2 节标记）

## 3. 为什么"没数据"—— 按情况排查

### 情况 1：前端没传 `sys_org_number`（最常见）

所有 zhgd 接口都按 `sys_org_number`（项目号）过滤。**不传就一条都查不到。**

当前测试数据统一用 `DW001`。

### 情况 2：表里真的没数据

先跑这条 SQL 自己看：

```sql
SELECT 'gglist/gztj(施工人员台账)' t, COUNT(*) c FROM TUD_DFDCSGRYTZ WHERE NVL(sys_deleteflag,0)=0
UNION ALL SELECT 'gglist在场数', COUNT(*) FROM TUD_DFDCSGRYTZ WHERE NVL(sys_deleteflag,0)=0 AND jcrq<=TRUNC(SYSDATE) AND (tcrq IS NULL OR tcrq>=TRUNC(SYSDATE))
UNION ALL SELECT 'zhgd_aqwgh', COUNT(*) FROM ZHGD_AQWGH WHERE sys_org_number='DW001'
UNION ALL SELECT 'cjdw(SG_RYXX_M)', COUNT(*) FROM SG_RYXX_M WHERE sys_org_number='DW001'
UNION ALL SELECT 'kqcr(今日进出)', COUNT(*) FROM ZHGD_EMP_RINOUT_TODAY_V WHERE sys_org_number='DW001'
UNION ALL SELECT 'zcryhz(在场汇总)', COUNT(*) FROM ZHGD_MJTJDW_V WHERE sys_org_number='DW001'
UNION ALL SELECT 'clrk(车辆)', COUNT(*) FROM VIEW_ZHGD_CLJCJL WHERE sys_org_number='DW001'
UNION ALL SELECT 'lskq(历史考勤)', COUNT(*) FROM VIEW_ZHGD_RYJCSJ WHERE sys_org_number='DW001'
UNION ALL SELECT 'kqtrend(考勤趋势)', COUNT(*) FROM ZHGD_DWRYQX_V WHERE sys_org_number='DW001'
UNION ALL SELECT 'jklist(监控)', COUNT(*) FROM VIDEOINFO WHERE sys_org_number='DW001'
UNION ALL SELECT 'ryzzcard(人员信息)', COUNT(*) FROM VIEW_ZHGD_RYXX WHERE sys_org_number='DW001';
```

```sql
ORDER BY gp.sort, p.sort, m.sort;

-- 3) 某表有没有表单页面（有 binding_table = 有表单定义）
SELECT binding_table, COUNT(*) AS 字段数 FROM dy_form_field
WHERE LOWER(binding_table)='tud_dfdcsgrytz' GROUP BY binding_table;
```
