> 备份恢复、连接方式、自定义开发常用表、SQL 模板。

## 1. 连接方式

### 1.1 PostgreSQL / OpenGauss（高斯）

```bash
# 本地直连
gsql -p 54321 -U omm -d gaussdb

# 常用参数
-p 54321       # 端口
-U omm         # 用户
-d gaussdb     # 数据库
-W             # 密码（交互）
```

默认 schema：`plant`。查表请加前缀 `plant.表名`，或先执行：

```sql
SET search_path = plant;
```

### 1.2 MongoDB

```bash
mongo -u plant -p '<密码>' --authenticationDatabase admin plant
```

端口：`27017`，库：`plant`。

### 1.3 自定义接口里连 PG

自定义接口平台一般暴露 `db.plant2x.select([...])`。示例见 [[01-自定义开发/自定义表单开发实战#2.12 自定义接口 + 存储过程：按表名生成编号]]。

### 1.4 MCP 数据库连接（WorkBuddy）

WorkBuddy 已连 `mcp__dbx`。让 AI 直接查表时，提供以下信息：

- 连接名：按现场给（如 `test-pg`、`prod-pg`）
- 数据库类型：PostgreSQL / MySQL / MongoDB
- Host / Port / 数据库名 / schema
- 账号密码（如允许）

查表前先让 AI 执行 `mcp__dbx__dbx_list_tables` 或 `mcp__dbx__dbx_describe_table`，不要让它编造字段名。

## 2. 备份恢复

### 2.1 PostgreSQL 备份

数据量大时先清日志：

```sql
TRUNCATE TABLE sys_application_log;
TRUNCATE TABLE sys_business_log;
TRUNCATE TABLE sys_data_audit_log;
```

```bash
su - omm

gs_dump -p 54321 -U omm -Fp -n plant \
  -T plant.sys_application_log \
  -T plant.sys_business_log \
  -T plant.sys_data_audit_log \
  -f /data/tmp/plant_$(date +%Y%m%d).sql gaussdb && \
gzip -f /data/tmp/plant_$(date +%Y%m%d).sql
```

### 2.2 传输到目标服务器

```bash
rsync -avP -e "ssh -p <端口>" /data/tmp/plant_$(date +%Y%m%d).sql.gz <用户>@<内网地址>:/data/tmp/
```

目标目录不存在先创建：

```bash
ssh <用户>@<内网地址> "mkdir -p /data/tmp"
```

### 2.3 目标服务器恢复

**谨慎操作**：建议先备份旧 schema。

```bash
gsql -p 54321 -U omm -d gaussdb -c 'ALTER SCHEMA plant RENAME TO plant_bak_$(date +%Y%m%d);'
```

解压导入：

```bash
gunzip -c /data/tmp/plant_20260518.sql.gz | gsql -p 54321 -U omm -d gaussdb
```

验证：

```bash
gsql -p 54321 -U omm -d gaussdb -c 'SELECT count(*) FROM plant.核心表名;'
```

### 2.4 MongoDB 备份恢复

```bash
# 备份
mongodump --host 127.0.0.1 --port 27017 -u plant -p '<密码>' \
  --authenticationDatabase admin -d plant -o /data/tmp/mongodb_$(date +%Y%m%d)

tar -czf /data/tmp/mongodb_$(date +%Y%m%d).tar.gz -C /data/tmp/ mongodb_$(date +%Y%m%d)

# 传输
rsync -avP -e "ssh -p <端口>" /data/tmp/mongodb_$(date +%Y%m%d).tar.gz <用户>@<内网地址>:/data/tmp/

# 恢复
tar -xzf /data/tmp/mongodb_$(date +%Y%m%d).tar.gz -C /data/tmp/
mongorestore --host 127.0.0.1 --port 27017 -u plant -p '<密码>' \
  --authenticationDatabase admin --drop --dir /data/tmp/mongodb_$(date +%Y%m%d)/
```

## 3. 自定义开发常用表

### 3.1 表单定义相关

| 表 | 用途 |
| :--- | :--- |
| `dy_form` | 表单定义，`formAttributeJson` 是 JSON 字符串 |
| `dy_form_field` | 表单字段定义 |
| `dy_form_button` | 按钮定义，`clickEvent` 可能 URL 编码 |
| `dy_form_category` | 表单分类 |

### 3.2 自定义接口 / 菜单 / 权限

| 表 | 用途 |
| :--- | :--- |
| `sys_api_info` | 自定义接口注册 |
| `sys_group_info` | 自定义接口分组 |
| `sys_menu` | 功能菜单 |
| `sys_permissions` | 按钮权限 |
| `sys_dictionary_category` / `sys_dictionary_value` | 代码表主/子表 |

### 3.3 库存 / 出库 / 领料相关（来自 2026 工作日志）

| 概念 | 表 | 关键字段 |
| :--- | :--- | :--- |
| 出库 | `tma_storage_out` | `state`、`type`（URL 类型）、`ckzt` |
| 出库明细 | `tma_storage_out_details` | `state`、`withdraw_stock_state` |
| 领料 | `tma_requisition` | `state`、`ckzt` |
| 领料明细 | `tma_requisition_details` | `state`、`ckzt`、`avail_stock_count` |
| 库存明细 | `tma_material_stock` | `available_stock`、`actual_stock`、`ycksl` |

> 表名以实际数据库为准。不确定时让 AI 连数据库 MCP 现场查。

## 4. 常用 SQL 模板

### 4.1 清日志

```sql
TRUNCATE TABLE sys_application_log;
TRUNCATE TABLE sys_business_log;
TRUNCATE TABLE sys_data_audit_log;
```

### 4.2 改 schema 名（备份旧库）

```sql
ALTER SCHEMA plant RENAME TO plant_bak_20260908;
```

### 4.3 查某个表单定义

```sql
SELECT id, name, code, type, form_attribute_json
FROM dy_form
WHERE name LIKE '%出库%';
```

### 4.4 查自定义接口

```sql
SELECT id, name, api_url, method, sql_content
FROM sys_api_info
WHERE name LIKE '%编号%';
```

### 4.5 通用分页查询模板

```sql
SELECT
  t.id,
  t.name,
  t.create_time
FROM some_table t
WHERE t.sys_deleteflag = 0
  AND (#{keyword} IS NULL OR t.name LIKE '%' || #{keyword} || '%')
ORDER BY t.create_time DESC
LIMIT #{pageSize} OFFSET #{offset};
```

## 6. 调试建议

- **自定义接口调试**：后台 → 自定义接口 → 「测试」按钮。
- **直接 SQL**：`gsql -p 54321 -U omm -d gaussdb` 手测。
- **慢 SQL**：`sys_application_log` / `sys_business_log` 里看。
- **索引**：`EXPLAIN ANALYZE` 必加索引。
- **多环境**：改前先备份，单表单试点，再全量。
