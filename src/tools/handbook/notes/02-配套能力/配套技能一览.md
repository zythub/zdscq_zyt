# 配套技能一览

> 手册只讲「怎么写代码」。其余活儿（回归、打包、发布、上下线、排障、抓取）都做成了技能，你不用记脚本，对 AI 说需求，它会加载对应技能去干。这份是总目录。

> **用之前先把两样给 AI**：环境地址（host，形如 `http://ip:port`）和登录后的 token（浏览器 F12 → Application → Local Storage → `access_token`，请求头 `Authorization: Bearer <token>`）。这两项每次单独说，别写进知识库。技能的查库、抓包都靠它。

## 技能清单

| 技能 | 干啥的 | 你这样说 |
| :--- | :--- | :--- |
| **web-form-regression** | 表单增删改查回归、打印验证、页面排障（**走接口不点 UI**） | 「给 XX 表单做一轮增删改查回归，出证据截图」 |
| **dynamic-form-datasource** | 数据源批量注入/替换、目录树截断排障、子表带值、编号规则溯源 | 「给这 30 张表单注入数据源」「下拉树只显示一部分怎么修」 |
| **batch-api-switch** | 资源接口批量上/下线（先全下线再全上线才生效），支持排除名单和自动复核 | 「把这个分组下线的接口全上线」「按分组 cycle 一下接口」 |
| **prp-function-publish** | 功能批量发布/重挂到菜单（API 版），替代浏览器自动化 | 「把未发布的功能批量发布到菜单」「把功能重挂到新分类目录」 |
| **env-debug** | 环境接入与排查：路由、token、数据库只读核对、改了不生效三查 | 「排查一下这个环境表单为什么没生效」 |
| **form-browser-capture** | 表单抓取（补充）：把线上表单定义沉淀回知识库 | 「抓一下 XX 表单的 created 和按钮事件」 |
| **wbipc-api-automation** | WorkBuddy 本机接口自动化：脚本不碰 token，让 daemon 代发登录态请求 | 「写个本机脚本自动签到/查积分」 |
| **update-package** | 现场更新包：打包 SQL（MongoDB 设计段+业务库段）、数据表 Excel 导出、Word 更新说明、开发记录 | 「打更新包」「把这张表导出 Excel 给现场」 |

## 使用约定

- **环境地址和 token 都不落库**：每次由你单独提供（见上方提示），AI 只在当前会话用。
- **数据库只读**：技能查库只 `SELECT` 核对，不在库里改数据。
- **改前先备份 / 先试点**：批量操作类技能都遵循 dry → one → all，别一上来全量。
- **技能是仓库**：更细的接口契约、脚本参数、坑位都在技能 SKILL.md 里，这份只是入口。

## 实战之外的「写代码」补充

- 自定义接口怎么写（单条 SQL、`#{name}` 占位、CALL 存储过程、多行第二行静默忽略）→ 见实战附录。
- 环境怎么连、功能怎么批量发布、线上代码规律 → 都在上面技能表里，按名字让 AI 加载对应技能。
