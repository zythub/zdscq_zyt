# 个人知识库 · 首页

手册只讲一件事：自定义表单怎么写代码。其他能力（回归测试、批量发布、上下线、打包、环境排查）做成了技能，对 AI 说需求就行，方法说明在技能包自带。

约定四条：以实测为准（和官方文档冲突时信实测）；环境地址和 token 每次单独提供，不写进文档；数据库只读，查库核对走 MCP，改数据走平台界面；控件 id 每个环境不一样，示例里的 id 只是占位。

## 手册

- [[01-自定义开发/自定义表单开发实战|自定义表单开发实战]] —— 主体。查字段 id 的三条路、事件列表、ctx 全部方法（每个 API 配一个线上实例）、子表、平台扩展、常见坑，附录里还有自定义接口怎么写
- [[01-自定义开发/批量配置与自动化|批量配置与自动化]] —— 给几十张表单批量注入事件、资源接口批量上下线
- [[01-自定义开发/达梦SQL交付规范|达梦SQL交付规范]] —— 往达梦库交付 SQL 前必读。达梦 VARCHAR 按**字节**算（汉字 3 字节，照抄 MySQL 窄列宽必报 -6169）、ALTER/CREATE 幂等写法、时间列格式、幂等去重，以及配套的**字节级静态体检器** `工具/dm_sql_lint.py`（交付前跑一遍，0 问题再发）
- [[01-自定义开发/智慧工地数据来源总说明|智慧工地数据来源总说明]] —— 给测试和用户看：接口读哪张表、数据在哪个菜单页面维护、**没数据时怎么排查**（96 个接口全核对）。含 3 个前端调了但后端没有的 404 接口、`zypsl`/`lxjxsbmx` 两个含义对不上的接口

测试、批量发布、环境排查这些能力在技能包里（`.claude/skills/<技能名>/SKILL.md` 自带方法说明），不再单独成篇；表单打包导出 SQL 是 update-package 技能的支撑文档，只在本库存档。

## 技能（`.claude/skills/`，对 AI 说需求即可命中）

| 你想干什么 | 技能 | 对 AI 说 |
| :--- | :--- | :--- |
| 表单增删改查回归、打印验证、页面排障 | `web-form-regression` | 「给 XX 表单做一轮增删改查回归，出证据截图」 |
| 数据源批量注入/替换、下拉树层级排障 | `dynamic-form-datasource` | 「把 XX 数据源批量注入到名称带"报审"的表单」 |
| 子表从主表带值、编号规则溯源 | 不用技能，查实战 §5.2/5.5 + §11 | 「XX 表单导入 Excel 后子表要自动带主表合同编号」 |
| 资源接口批量上/下线（先全下线再全上线才生效） | `batch-api-switch` | 「把这个分组的接口重新发布一遍」 |
| 功能批量发布到菜单 | `prp-function-publish` | 「把未发布的功能批量发布到菜单」 |

## 环境准备

- 环境地址 + token 每次由使用者单独提供，本库不预置。
- token 取法：登录后 F12 → `localStorage.access_token`，请求头 `Authorization: Bearer <token>`。
- 在本目录起 Claude Code 会话会自动加载 `CLAUDE.md`（技能路由和约定都在里面）。
