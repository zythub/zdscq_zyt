- 表单设计：`http://<内网地址>/web/#/custom/form-definition/design`

- API Host：`http://<内网地址>/apis/`
- Token：`Bearer <你的Token>`

## 上手路线（统一，不分开发与实施）

> 本手册是沉淀型资产，照下面顺序走即可上手——不是某天的临时待办，越用越厚。

1. 先读 [[01-自定义开发/表单事件API参考]] —— 搞清事件脚本怎么写、`ctx/params` 有哪些方法、19 个事件何时触发（官方文档浓缩版）
2. 照抄范例 [[01-自定义开发/自定义表单开发实战]] —— 真实出库表单代码（弹窗带数据、批量删子表、渲染过滤、自动编号、序列化等），复制即用
3. 写平台扩展（弹窗/列表渲染/筛选）查 [[01-自定义开发/平台扩展API]] —— outInfo 全集、openFormModal、renderText 等官方未覆盖的 API
4. 批量改动看 [[01-自定义开发/批量配置与自动化]] —— 一次给几十张表单注入事件 + 自动化测试
5. 写后端逻辑查 [[03-自定义接口/自定义接口编写指南]] 与 [[02-数据库/数据库速查与连接]]
6. 卡住/报错：先查 [[04-环境接入与排障/常见问题FAQ]]，再按 [[04-环境接入与排障/环境与排查方法]] 用浏览器/数据库 MCP 自己查，**不要硬编**
