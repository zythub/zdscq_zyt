# 常见问题 FAQ

> 二次开发 / 现场使用中最常碰到的问题与解答。新增问题请用 [[模板/问答模板]]。

## 通用

### Q: 改了表单保存后没生效？

排查：
1. 浏览器强刷（`Ctrl+Shift+R`），或清缓存。
2. 检查是否保存到「正式」环境（部分环境差异）。
3. 看 `PUT /apis/dynamic/form` 是否返回 200，前端是否有报错。
4. 确认表单已发布：去 [[环境与排查方法]] 的表单发布页查发布状态。

### Q: 控件 id 在测试/正式环境不一致怎么办？

A: 不要硬编码 code，用 `getControlIdByField(formInstance, dataField)` 实时解析。见 [[01-自定义开发/平台扩展API#6. 通过数据库字段名找控件 id（getControlIdByField）]]。

### Q: 接口 405 / 404？

A: 检查路径：
- 保存表单用 **`PUT /apis/dynamic/form`**（不是 `/form/{id}`、不是 `/form/attribute`）
- 按钮保存 `PUT /apis/dynamic/form/button`

### Q: 出库/领料点了没反应？

A: 先看后端日志（慢 SQL / 锁表），再检查：
- `tma_material_stock` / `tma_requisition_details` 的可用库存
- 流程节点是否走到了「领料中」
- 详见 [[01-自定义开发/自定义表单开发实战#1. 出库专题（真实表单）]]

### Q: 报「数据权限不足」？

A: 检查数据权限配置（按机构 / 角色）；可临时切换登录人确认。

### Q: 自定义接口慢？

A:
1. 加索引
2. 避免 `LIKE '%xxx%'` 全表扫
3. 拆 SQL / 走物化视图
4. 看 `sys_application_log` / `sys_business_log`

### Q: AI 给不出答案怎么办？

A: 让它连数据库 MCP 或浏览器 MCP 自己看。方法见 [[环境与排查方法]]。
