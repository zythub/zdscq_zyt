# 常见问题处理

> 用法：**按「症状」查**。先在这里定位，再去对应篇章看细节。
> 这篇只放高频、反复踩的问题；一次性的环境问题放 02-配套能力。

## 一、改了没反应

| 症状 | 怎么处理 | 细节 |
| :--- | :--- | :--- |
| 改完事件代码 / 表单设计，页面还是老样子 | **刷新页面**（Ctrl+Shift+R）。框架已自动发布，**不需要手动“重新发布”** | 平台机制 |
| 保存了但完全没变化 | 确认改的是同一张表单（多环境容易改错库）；F12 看 console 有无报错 | 02-配套能力 |
| 报 405 / 401 | 405 = 接口路径错；401 = token 过期，重新登录 | 02-配套能力 |

## 二、代码写了不执行

| 症状 | 原因 | 解法 |
| :--- | :--- | :--- |
| 代码里写了函数，**不执行也不报错** | 平台脚本**禁止嵌套 function**（函数体内再定义 function，含 `forEach(function(){})` 回调） | 循环用 `for`，回调用**箭头函数** |
| console 里啥都没有 | 事件槽挂错位置：子表按钮代码在 `actions[i].event`，不是主表按钮槽 | 对照设计器的事件面板 |
| 取值拿到 undefined | 控件 id 不对（id 跨表单/跨环境全不同） | 三条路查 id，见实战 §1；或用 `getControlIdByField` 反查 |

## 三、子表 / 控件操作

| 症状 | 原因 | 解法 |
| :--- | :--- | :--- |
| 改一行子表，**整个子表行全没了** | `setArrayValue(子表id, 数组)` 是**整表替换** | 改单格必须 `setArrayValue(子表id, 行号, 字段id, 值)` |
| 子表加行后立刻读不到新行 | 加行是异步渲染 | `setTimeout(100ms)` 再读，或走 `getArrayFormApi().append` |
| 行内取主表字段取不到 | 不知道要不要传 instanceId | 行内直接 `ctx.getValue(主表字段id)`，会回落主表 |
| 想“只能弹窗选、不能手输” | 设计器勾 `readonly`/`disabled` 会把弹窗按钮一起禁掉 | created 里 DOM `setAttribute("readonly", true)`，见实战 §2.18 |

## 四、选人控件（org）

| 症状 | 原因 | 解法 |
| :--- | :--- | :--- |
| 人员白名单过滤**不生效** | 普通版 `customFilterFn(users, orgs, pos)` 是废的，`users` 恒为空 | 用**高级版** `customFilterFnAdvanced(params, ctx, block)`，白名单筛 `params.users`，见实战 §2.19 |
| 只想显示某个部门的人 | 默认全公司 | `ctx.setInstance(控件id, "currentOrg", 部门id)`，见实战 §2.20 |
| 部门清空后还锁在旧部门 | `currentOrg` 没跟着清 | 部门清空时把 `currentOrg` 置 `""` |

## 五、交付 / 数据库

| 症状 | 原因 | 解法 |
| :--- | :--- | :--- |
| 达梦建表后中文被截断 | 达梦 `VARCHAR(n)` 的 n 是**字节**，UTF-8 汉字占 3 字节 | 列宽按字符数 ×3 放大，详见 **达梦 SQL 交付规范（踩坑沉淀）** |
| 现场执行 SQL 报无效的列名 | 源库和目标库表结构不一致 | 迁移前先做列级对比，只对“两边都有”的表出补列语句 |
| 页面对了、库里数据不对 | 页面渲染 ≠ 落库 | 让 AI 走 dbx 查库核对（只读），别只看页面 |

## 六、找东西

| 想找 | 去哪 |
| :--- | :--- |
| 某个控件 id / 字段绑定 | 设计器复制、`dy_form_field` 查库、`form_attribute` 接口三选一（实战 §1） |
| 现成代码怎么写 | 自定义表单开发实战（API + 实例）/ 表单实测代码库 |
| 批量改几十张表单 | 02-配套能力（批量配置） |
