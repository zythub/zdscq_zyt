# 自定义接口编写指南

> 来源：`bst/自定义表单更新.md` + `bst/自定义表单.md`。重点是端点、表清单、存储过程模板。

## 1. 接口调试：获取 / 更新 表单 SQL

### 1.1 获取表单定义

```
GET http://<内网地址>/apis/dynamic/form/{formId}
Authorization: Bearer <你的Token>
```

返回 `data.formAttributeJson` 是**字符串**，需要 `JSON.parse`。

### 1.2 保存表单（全量替换）

```
PUT https://<host>/apis/dynamic/form
Authorization: Bearer <token>
Content-Type: application/json

{ ... 整表单对象（含 id）... }
```

> ⚠️ 路径是 **`/apis/dynamic/form`**（集合），不是 `/apis/dynamic/form/{id}`（405），也不是 `/apis/dynamic/form/attribute`（dyFormFields 会变 null）。

### 1.3 按钮相关

- 获取按钮：`GET /apis/dynamic/form/button/{formId}?subFlag=`
- 保存按钮：`PUT /apis/dynamic/form/button`（body=整按钮对象）
- `clickEvent` 存储**可能是 URL 编码**（含 `%` 先 `decodeURIComponent`，保存再 `encodeURIComponent`）

## 3. 写自定义接口的注意事项

1. **入参要用占位符 `#{name}`**，平台会做参数化；不要直接拼字符串（防注入）。
2. **出参用 `SELECT` 起头**，平台会把它当列表解析。
3. **存储过程**：`db.plant2x.select([CALL sp_name(#{p1}, #{p2});])`
4. **表名动态**：用存储过程 + `PREPARE/EXECUTE`，见下文模板。
5. **事务/批量**：平台自定义接口一个调用 = 一个 SQL，跨表/事务需要在存储过程里控制。
6. **限流/超时**：超过 30 秒的大查询要分页或加索引。
7. **日期格式**：PostgreSQL `to_char(now() AT TIME ZONE 'Asia/Shanghai', 'YYYY-MM-DD HH24:MI:SS')`。
8. **达梦 / MySQL 兼容**：标识符 ≤ 63 字符；字符串拼接用 `||`（PG）/ `CONCAT`（MySQL/DM）。
9. **平台会把脚本里的 `"` → `&quot;`、`&&` → `&amp;&amp;`**，模板里提前规避。

## 5. 模板：通用查询

```sql
SELECT
  t.id,
  t.name,
  t.create_time
FROM some_table t
WHERE t.sys_deleteflag = 0
  AND (#{keyword} IS NULL OR t.name LIKE '%' || #{keyword} || '%')
ORDER BY t.create_time DESC
LIMIT #{pageSize} OFFSET #{offset};
```

## 6. 调试建议

- **平台调试**：后台 → 自定义接口 → 「测试」按钮。
- **直接 SQL**：`gsql -p 54321 -U omm -d gaussdb` 手测。
- **日志**：`sys_application_log` / `sys_business_log` 里看慢 SQL。
- **索引**：`EXPLAIN ANALYZE` 必加索引。
- **多环境**：改前先备份，单表单试点，再 all。
